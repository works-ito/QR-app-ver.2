# QR在庫管理｜本番運用版

株式会社ワークスで現場運用しているQR在庫管理アプリです。

> **このリポジトリは本番環境です。**  
> 動作確認が完了した変更だけを反映してください。

## 現在の位置づけ

- リポジトリ名：`QR-app-ver.3`
- 運用上の名称：QR在庫管理 本番版
- 中身は新ウィザードへ移行済みで、実質的にはver.3相当です
- 開発・検証は `QR-app-development` で行います

## 主な機能

- 通常受付／イレギュラー受付
- 個体管理品・簡易個体管理品・REC・数量管理品への対応
- QR連続読取と最新状態の照合
- 二重出庫・不正な状態遷移の防止
- 数量管理品の検品、完成機・検品廃棄への振り分け
- 一括送信と5分以内の送信取消
- 出庫・返却写真の保存
- 伝票写真から顧客名・現場名をAI解析

## RECの取扱い

- `REC01-001` などの通常作業は個体管理品として処理します
- 校正中・校正完了・交換完了のみREC専用処理です

## 主なファイル

- `index.html`：正式な本番画面
- `datamatrix-test.html`：旧URLから正式入口へ転送する互換ファイル
- `styles.css`：画面デザイン
- `app.js`：画面制御・QR読取・GAS連携
- `version.json`：キャッシュ更新用バージョン

## 更新時の注意

本番へ反映する前に、開発用リポジトリで構文確認と実機動作確認を行います。GASを変更した場合は、GAS側の保存と新バージョンのデプロイも必要です。
